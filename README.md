## Repository Naming Convention

To make it easier to understand the purpose of each repository, I use the following prefixes:

| Prefix    | Meaning     | Description                                                                                                                                                                                        |
| --------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`prj`** | **Project** | A complete application that typically includes authentication, validation, data persistence, testing, and other production-ready practices.                                                        |
| **`cls`** | **Class**   | A project built while following a course, tutorial, book, or other learning resource. Its primary purpose is studying and practicing the concepts presented.                                       |
| **`sbx`** | **Sandbox** | A small project created to experiment with an algorithm, technology, framework, library, or specific concept. These repositories are intended for learning, prototyping, and hands-on exploration. |

> The prefixes indicate the purpose of a repository and do not necessarily reflect its complexity, quality, or level of completion.
